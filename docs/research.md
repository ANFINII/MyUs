## note の有料記事

調べた日：2026-11-18。確かめ方：公式ヘルプと解説記事。

- 記事ごとに投稿者が値段を付け、読者が1本ずつ買う。ふつうの会員は100〜50,000円、note プレミアム会員は上限が100,000円
- エディターで段落を選び、有料エリアの線を入れる。線より前は誰でも読め、後ろは値段と購入のボタンに替わる

- ほかに、記事をまとめて売る有料マガジンと、月額で入るメンバーシップがある

## note.com のドメイン

調べた日：2026-11-19。確かめ方：記事。

- 2014年に `note.mu` で始め、2018年12月に `note.com` と `note.jp` を高い値段で買い取り、2019年11月に移った
- 取った理由は、覚えてもらいやすさ、検索からの流入、海外に出る足がかり、競合に取られない守り
- 取れる名前で始め、育ってから良いドメインを買う順番は、`myus.media` で始める MyUs の方針と同じ。ただ `myus.com` は今も事業に使われていて、買い取れる見込みは低い
- あとで移れるように、ドメインをコードに直接書かない。HSTS の preload はドメインを決めるまで入れない。移ったあとも古いドメインを持ち続けて転送する

- [Business Insider Japan：note.com 取得の経緯](https://www.businessinsider.jp/post-184352)
- [note のサービス URL を note.com へ移行](https://newscast.jp/news/692041)

調べた日：2026-11-20。確かめ方：知識。率は変わることがあるので目安。

| サービス | 運営の取り分 | 投稿者の取り分の目安 |
|---|---|---|
| BOOTH | 5.6%と1件22円 | 約94% |
| pixivFANBOX | 10% | 約90% |
| Patreon | 10%と決済の手数料 | 約85〜87% |
| Substack・Gumroad | 10%と決済の手数料 | 約85〜87% |
| MyUs | 15%。決済の手数料は運営が負担 | 85% |

- MyUs の15%は真ん中くらい。決済の手数料も込みなので、投稿者には売上の85%がそのまま入ると言える

- 手数料は下げるのは簡単で、上げるのは難しい。下げるなら期間を決めたキャンペーンにする

## 曲の権利

調べた日：2026-11-19。確かめ方：知識。

- YouTube でカバー曲を投稿できるのは、YouTube が著作権管理団体と包括の契約を結んでいるから
- 管理団体が許諾するのは作詞・作曲の権利だけ。録音の権利はレコード会社などが持つので、原曲の音源はそのまま使えない
- 包括の契約は聴かせる配信を許すもので、ファイルの販売までは含まないことが多い

## YouTube の広告

調べた日：2026-11-20。確かめ方：知識。

| 項目 | やり方 |
|---|---|
| 申し込み | 広告主は Google 広告から出す |
| 料金 | 予算の上限を決めて入札する。30秒以上見られたときかクリックされたときに払う形と、表示1,000回ごとに払う形がある |
| 出す相手 | 年齢・地域・興味・キーワード・出すチャンネルで絞れる |
| 審査 | 出す前に、広告のポリシーに合うかを自動と人の目で確かめる |
| 長さ | 飛ばせない広告は15秒まで、6秒だけの短い広告もある。飛ばせる広告は上限がないが、効果が出やすいのは15〜30秒 |
| 広告をなくす | YouTube Premium に入ると広告が出ない |

- 広告の業界では、相手を絞るほど単価が上がり、長いほど高くなる。人の多い地域や、広告を出したい会社が多い分野も高くなる

## 広告の売り方

調べた日：2026-11-20。確かめ方：知識。

| 売り方 | 主なサービス | 相手 |
|---|---|---|
| 自分で申し込む | Google・YouTube・Meta・X・TikTok・LINE | 個人や小さなお店も出せる。1日数百円からでも始められる |
| 問い合わせて個別に見積もる | ニュースサイト・雑誌のサイト・専門の小さなメディア | 主に会社。最低でも数万円からが多い |

- 小さめのメディアが個別の見積もりにするのは、見る人が少なく仕組みを作っても割に合わない、1件ごとに内容を確かめたい、会社相手なら1件の額が大きい、から
- 個人は、自分で申し込めて少額から始められる大きなサービスを使う。個人に出してもらうなら、自分で申し込めて安い形が要る

## 参考にした法律の決まり

調べた日：2026-11-20。確かめ方：知識。一般的な読み方なので、始める前に専門家に確かめる。

- 個人情報保護法：取得する目的、運営者の名前と住所、苦情を受け付ける窓口、安全管理の措置を、本人が知れる状態にする。住所は請求があれば開示する形でもよい
- 資金決済法：お金で買えるポイントは前払式支払手段になり、使われずに残った額が1,000万円を超えると、届け出と、その半分の額の供託が要る。無料で付けるだけなら当たらない。お金に換えられると、送金の業として登録が要ることがある
- 特定商取引法：申し込む前に表記を見られれば足りる。サイトのすべての画面に置くことまでは求められていない
