主なリソース

AWS
  • Route 53・ACMmyus.media の登録と DNS。CloudFront の証明書は us-east-1
  • CloudFront ×3フロント・API・メディア。API は VPC オリジンでプライベートの EC2 につなぐ
  • EC2 t4g.smallプライベートサブネット・パブリック IP なし。Docker Compose で 4 コンテナ。メモリの上限とスワップ 2GB
  • VPC・NATパブリック・app・datastore の 3 層。外への出口は fck-nat（t4g.nano）。S3 は Gateway エンドポイント
  • RDS db.t4g.microMySQL 8.4・strict。外への経路のないサブネット。データは指示があるまで消さない
  • S3 ×3フロント・公開のメディア・ハイレゾ。ハイレゾは 5 分の署名付き URL
  • SESnoreply@myus.media。DKIM・SPF・DMARC・MAIL FROM。今はサンドボックス
  • Systems Manager/myus/prod/ の設定、Run Command でデプロイ、Session Manager で DB にトンネル
  • ECRmyus-backend。backend・worker・encoder が同じイメージ
  • CloudWatch・SNSアラームを東京と us-east-1 の SNS からメールで送る
  • OrganizationsSCP で使えるリージョンを東京と us-east-1 に絞る
