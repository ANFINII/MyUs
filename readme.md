# MyUs

## MyUsは総合メディアプラットフォームを目指したSNSになります。

「My Idea Know Us」が名称の由来です。

### 主な機能
- Video投稿
- Music投稿
- Comic投稿
- Picture投稿
- Blog投稿
- Chat投稿

### 視聴機能
- 動画・音楽のストリーミング配信 (HLS)
- 再生速度の変更
- 漫画ビューア
- 画像のライトボックス

### 管理画面
- メディア管理 (Video・Music・Comic・Picture・Blog・Chat)
- 広告管理
- 新規作成・編集
- ブログのリッチテキストエディタ
- チャンネルの切り替え
- 一覧のソート・ページング
- 一括削除
- 公開状態の表示

### アカウント機能
- サインアップ (メール認証)
- ログイン
- ログアウト
- プロフィール設定
- プロフィール編集
- マイページ設定
- マイページ編集
- チャンネル作成
- ユーザーページ
- 退会処理
- パスワード変更
- パスワードリセット

### 検索機能
- 検索
- 検索タグ
- 投稿ハッシュタグ

### API (非同期通信)
- いいねボタン
- フォローボタン
- コメント(投稿、編集、削除)
- リプライ(投稿、編集、削除)

### WebSocket (双方向通信)
- スレッド対応
- chatコメント(投稿、編集、削除)
- chatリプライ(投稿、編集、削除)

### その他機能
- 通知
- 通知設定
- 急上昇
- 利用規約
- Knowledge Base
- 広告表示
- フォロー&フォロワー 一覧表示
- チャンネル登録・登録チャンネル一覧
- 多言語対応 (日本語・英語)
- 料金プラン (Stripe のサブスクリプション・プラン変更・解約)
